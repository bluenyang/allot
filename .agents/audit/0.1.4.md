   `R/test/v11a.log`와 `v11b-run2.log`는 실제 클라이언트의 도구 10개, 제안 성공, 세션 API 적용·되돌리기를 증명한다. 그러나 확인 단계는 `POST /api/proposals/:id/apply` 호출이다. `v11b.sh`도 이를 명시한다. 별도 V-10의 화면 E2E가 통과한 사실은 이 실제 클라이언트 제안을 화면에서 확인했다는 증거가 아니다. 이 대체에 대한 조정 기록도 없다.

3. **V-2의 비교 기준이 W-1 이전 데이터였는지 확인할 수 없다.**
