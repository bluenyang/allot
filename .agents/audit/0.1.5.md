- **F-2:** PL이 독립 원인별 커밋 분리안을 제시한다. 이미 원격에 올라간 이력은 사용자 지시 없이 재작성하지 않는다. 사용자가 이번 혼합을 수용한다면 해당 커밋과 사유를 명시한다.
- **F-3:** 실패한 확인에서 즉시 종료하고 정리는 별도 finally·cleanup으로 수행하도록 검사 스크립트를 보완한다. 서버 검사 실행권을 한 담당자에게 모으고, history의 실제 실패·후속 쓰기·정리 경위를 바로잡는다. 이미 확보한 최종 단독 실행 증거는 유지한다.
- **F-4:** 지출 제안을 :15174의 대기 중인 변경 화면에서 확인하고 변경 내역 화면에서 되돌리는 누락 경로를 검사한다. E2E summary·PR은 438의 데이터 전제 실패와 master 재현 실패를 구분한다. `delta.md`를 최종 구현에 맞춰 갱신·검토하며, V-11 사용자 확인은 계속 대기로 둔다.
- **F-5:** V-5 대체 이유·사본 DB·:15175 사용·정리 결과를 spec 조정과 history에 기록한다. 승인된 서버 경계의 예외 처리 여부는 사용자에게 명시한다. 원래 절차를 수행한 것처럼 기록하지 않는다.
- 감사 기록과 보완·사용자 처리도 후속 리뷰·게이트를 거쳐 PR에 반영한다. 마지막 head의 PR·검사 기록을 다시 수집하고, 머지는 사용자 지시를 기다린다.
